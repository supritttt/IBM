# Amul Topical Campaigns: Dataset and Power BI Dashboard

Class project "Market Campaign Comparisons": analysis of Amul's topical advertising (humor + wordplay + current events + consistent Amul Girl identity).

## Quick start: open the ready-made project

The folder contains a Power BI Project (`Amul_Campaign_Dashboard.pbip`) with the data model, date table, all measures and 3 report pages already built.

1. Unzip and copy the `data` folder to `C:\Amul_Power_BI\data` (or any location you like).
2. Double-click `Amul_Campaign_Dashboard.pbip` (needs Power BI Desktop, current version).
3. If the data does not load: **Home > Transform data > Edit parameters**, set `DataFolder` to the folder that holds `amul_campaigns_100.csv`, then **Close & Apply**.
4. **View > Themes > Browse for themes** > `powerbi/Amul_Theme.json`.
5. **File > Save as** `Amul_Campaign_Dashboard.pbix`.

The project was generated by script and has not been opened in Power BI Desktop here. If Desktop shows an error, use the manual steps below instead (they build the same dashboard).

## Data note

Illustrative dataset: ad categories and attributes follow how Amul's topical campaign works (outdoor, print and social ads reacting to events). Impressions, engagement, sentiment and recall values are **simulated**. Replace with real data before presenting them as findings.

## Build the dashboard in Power BI Desktop

### 1. Load and model

1. **Home > Get data > Excel workbook** > `amul_campaigns_100.xlsx` > tick `Amul_Ads` > **Load**.
2. Check types in **Table view**: `release_date` = Date, counts = Whole number, `engagement_rate_pct`, `positive_sentiment_pct`, `brand_recall_score`, `response_time_hrs` = Decimal.
3. **Modeling > New table**: paste the `Date` table from `DAX_Measures.dax`. Mark it as a date table.
4. **Model view**: drag `Date[Date]` to `Amul_Ads[release_date]` (one-to-many).
5. Select `Date[Month]` > **Sort by column** > `Month No`. Do the same for `Amul_Ads[month_name]` by `month_no`.
6. Create a table named `Measures` (Enter data, blank) and add every measure from the file.
7. **View > Themes > Browse for themes** > `Amul_Theme.json`.

## Questions the dashboard answers

- Which topics (cricket, Bollywood, Budget, festivals) get the most engagement?
